## 5. Gotchas that cost real time

- **Hebrew through the shell corrupts.** `curl -d '{"x":"עברית"}'` from git-bash writes `????` into D1. Always put JSON/SQL in a UTF-8 file and use `--data-binary @file` / `--file=`. Several local rows (nav labels, home/about headlines, CRM service name, CTA label) were corrupted this way and repaired with `json_set` from files; production was checked table-by-table and was never affected.
- **`portfolio_items.created_at` needs `DEFAULT (datetime('now'))`** — the shared `D1ContentPageStore.saveDraft` upsert never sets it, and SQLite aborts on a NOT NULL violation before the `ON CONFLICT` branch is considered.
- **First curl right after `wrangler deploy` can hit a stale edge node.** Retry once before concluding a deploy failed.
- **`scripts/curve-check.js` is not runnable directly** — it is a page-evaluate body for `node scripts/probe.mjs <url> "$(cat scripts/curve-check.js)"`.
- The STG reference site uses a custom smooth-scroll library: it cannot be scrolled/inspected by automation. The user's own screenshots were the only reliable view of it.

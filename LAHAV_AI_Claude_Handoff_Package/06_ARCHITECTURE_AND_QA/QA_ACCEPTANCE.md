# QA and Acceptance Checklist

## Scope

- [ ] All 13 approved pages/templates implemented.
- [ ] No unapproved Projects page exposed.
- [ ] Articles navigation/Home preview hidden when no approved articles exist.

## Brand

- [ ] Official logo assets only.
- [ ] Correct dark/color logo on light backgrounds.
- [ ] Correct white/light logo on dark backgrounds.
- [ ] Heebo headings; Assistant body/UI.
- [ ] LAHAV AI palette and gradient used consistently.

## Content truth

- [ ] No fake clients, testimonials, results, metrics or awards.
- [ ] No invented email/phone/address/legal identity.
- [ ] No unsupported integrations/platforms/technical capabilities.
- [ ] No fabricated copyright year.
- [ ] Stitch article content remains hidden/placeholder until replaced by real approved content.
- [ ] Privacy text is not treated as final until verified against actual production stack.

## RTL / responsive

- [ ] Native RTL layout at component level.
- [ ] Directional arrows/progressions are correct for Hebrew.
- [ ] Non-directional icons are not incorrectly mirrored.
- [ ] Desktop/tablet/mobile preserve the same page purpose and content hierarchy.
- [ ] Complex diagrams adapt intentionally rather than simply shrinking.

## Accessibility

- [ ] Keyboard navigation works.
- [ ] Visible focus states.
- [ ] Form labels/errors are accessible.
- [ ] Contrast is sufficient.
- [ ] Semantic headings and landmarks.
- [ ] Alt text where meaningful; decorative images hidden from assistive tech.
- [ ] `prefers-reduced-motion` supported.

## Performance / quality

- [ ] No unnecessary huge image payloads.
- [ ] Motion uses efficient transform/opacity patterns where possible.
- [ ] No scroll hijacking.
- [ ] No broken links or routes.
- [ ] No console errors.
- [ ] Forms have success/error/loading states.
- [ ] Metadata, canonical URLs, sitemap/robots and foundational SEO configured.
- [ ] 404 works for unknown routes.

## Conversion

- [ ] Discovery CTA is visually primary.
- [ ] WhatsApp remains secondary.
- [ ] Contact/Discovery flow is short and clear.
- [ ] No intrusive popups or floating WhatsApp button in V1.
